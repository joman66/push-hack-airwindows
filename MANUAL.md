# Airwindows on Push: controls

Open Push Hack Home (Shift + Help, or hold Help) and pick **AIRWIN**. Press **Help** to go back to Live. Play and Record still go to Live while Airwindows is open.

The audio goes through the slots from left to right: Input > 1 > 2 > ... > 8 > Output.

Every change happens right away. Nothing asks you to confirm.

## Everywhere

| Control | Does |
|---|---|
| Add | Open the browser to add an effect at the end of the chain |
| Volume encoder | Output gain (Shift = fine) |
| Help | Back to Live |

## Chain page

| Control | Does |
|---|---|
| Upper button 1-8 | Turn that effect on or bypass it (green = on, red = bypassed) |
| Lower button 1-8 | Open that effect's page |
| Lower button under **+ ADD** | Open the browser |
| Delete + upper or lower button | Remove that effect |

The status line shows the input and output meters, the DSP load and the output gain, or what is wrong with the audio.

## Browser

| Control | Does |
|---|---|
| Encoder 1 | Category |
| Encoders 2-4, jog wheel | Effect. Past the end of a category the jog wheel goes on into the next one. |
| Shift + jog wheel | Category |
| D-pad up/down | Effect |
| D-pad left/right | Category |
| Lower button 8 (ADD or REPLACE), jog press, Select | Take the selected effect and open its page |
| Lower button 1 (BACK) | Leave without a change |

The right side shows the selected effect's name, category, number of parameters and description.

## Effect page

| Control | Does |
|---|---|
| Encoders 1-8 | The 8 parameters of this bank (Shift = fine) |
| Delete + touch or turn an encoder | Back to the effect's default for that parameter |
| Page left/right, lower buttons | Parameter bank (only for effects with more than 8 parameters) |
| Upper 1 BACK | Back to the chain |
| Upper 2 ON / BYPASSED | Bypass |
| Upper 3 / 4 MOVE | Move this effect one slot left or right. The page follows it. |
| Upper 5 REPLACE | Open the browser at this effect, and swap in another one. Bypass is kept. |
| Upper 6 REMOVE | Remove this effect and go back to the chain |
| Upper 7 / 8, D-pad left/right | Previous / next effect in the chain |

Each knob shows the position (0-100) inside, and the value as the effect prints it (for example `-12.0000 dB`) below. A small dot above a knob means it is at its default.
